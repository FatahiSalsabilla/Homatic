Prinsip Kerja ⚙️

Alur sistem

📥

Input (Sensor)

Sensor LDR membaca intensitas cahaya (0–4095), sedangkan sensor hujan mendeteksi ada atau tidaknya air.

🧠

Proses (ESP32)

ESP32 membandingkan nilai sensor dengan batas kalibrasi, lalu menentukan tindakan yang diambil.

📤

Output (Aktuator)

Motor servo menggerakkan jemuran (0° masuk, 90° keluar) dan LED menyala sebagai lampu rumah.

📱

Monitoring (Blynk)

Data dikirim ke Blynk Cloud melalui Wi-Fi, sehingga sistem dapat dipantau dan dikendalikan dari jarak jauh.

Logika kerja 🧩

Otomatis · Cerah

LDR rendah dan tidak hujan: servo 90° (jemuran keluar), LED mati.

Otomatis · Hujan

Hujan terdeteksi: servo 0° (jemuran masuk) meskipun LDR masih terang.

Otomatis · Gelap

LDR melewati batas kalibrasi (misal 2000): LED menyala dan servo 0° karena embun malam tidak baik untuk jemuran.

Manual

Seluruh sensor diabaikan. Pengguna mengendalikan lampu dan jemuran penuh lewat tombol di aplikasi Blynk.

Datastream Blynk 📱

Pin Fungsi Nilai
V0 LDR 0–4095 (intensitas cahaya)
V1 Lampu 0 = Mati, 1 = Nyala
V2 Hujan 0 = Kering, 1 = Hujan
V3 Jemuran 0 = Masuk, 1 = Keluar
V4 Mode Auto 0 = Manual, 1 = Otomatis
