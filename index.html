Deskripsi Proyek 🏠

Homatic adalah sistem rumah pintar berbasis Internet of Things (IoT) yang mengotomatisasi dua pekerjaan rumah tangga sekaligus: melindungi jemuran dari hujan dan embun malam, serta mengatur pencahayaan rumah secara efisien. Sistem ini menggunakan mikrokontroler ESP32 yang terhubung dengan aplikasi Blynk IoT melalui jaringan Wi-Fi.

Pada mode otomatis, Homatic membaca kondisi lingkungan melalui sensor cahaya (LDR) dan sensor hujan. Pada mode manual, pengguna dapat mengendalikan lampu dan jemuran dari jarak jauh melalui aplikasi Blynk.

Proyek ini dikembangkan oleh Kelompok 1 di SMKS PGRI 1 NGAWI sebagai proyek akhir semester untuk menghadirkan solusi rumah tangga yang praktis, hemat energi, dan mudah dioperasikan.

Fitur Utama

🔁

Dual Mode

Mode otomatis berbasis sensor dan mode manual lewat aplikasi Blynk.

📶

Multi Wi-Fi

Menyimpan beberapa Wi-Fi dan menyambung otomatis ke jaringan terkuat tanpa memprogram ulang.

📊

Real-Time Monitoring

Nilai LDR dan status cuaca dipantau langsung dari mana saja melalui internet.

🛡️

Anti-Crash

Arsitektur non-blocking timer menjaga perangkat tetap responsif dan bebas macet.
